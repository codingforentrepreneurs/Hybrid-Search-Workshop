How it works

Keyword uses BM25 to rank matching terms. Semantic compares the meaning of your query with each movie’s plot. Hybrid combines both lists using Reciprocal Rank Fusion, rewarding movies that rank well in either search.

Try a character’s name, then describe a theme. Watch how the order changes.
